## Git branching
What is a branch?
A branch is a copy of your code,
you work on it without touching the main branch,
and when done, you merge it to the main branch.

Commands
git branch                              #list branches
git checkout branch -b branchname       #create and switch to new branch
git checkout main                       #switch to main branch
git merge branchname                    #merge the branch to main
git branch -d branchname                #delete branch
