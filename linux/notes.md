# My Linux Notes — Regan Ayiecho

## What I Understand

### sudo
- sudo = "superuser do"
- Temporarily gives admin power for ONE command
- Linux asks for YOUR password to confirm
- After command runs, you return to normal user
- Never use sudo unless necessary

### Paths
- Absolute path starts with / — works from ANYWHERE
- Relative path has no / — depends on where you are
- ~ is shortcut for /home/ayiecho

### File System Structure
/                    = root of everything
├── home/ayiecho/    = my home folder
├── etc/             = system config files
├── var/             = logs
└── usr/             = installed programs

### Key Lessons Learned
1. Spaces in filenames cause problems — use _ instead
2. rm has no recycle bin — deleted = gone forever
3. > overwrites, >> appends — know the difference
4. l and 1 look similar but are completely different
5. Always check pwd before running commands
